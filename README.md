# Funnel-dropoff-analysis

Objective:
Analyze the user funnel to identify where users leave before completing the purchase.

Tools Used:
- Python
- Pandas
- Matplotlib

Tasks Performed:
- Loaded CSV data
- Removed duplicate records
- Converted timestamps
- Counted unique users at each stage
- Calculated conversion rates
- Identified the biggest drop-off
- Visualized the funnel

Output:
- Funnel Report
- Drop-off Analysis
- Funnel Chart (PNG)
